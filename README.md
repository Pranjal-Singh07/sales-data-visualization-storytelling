# Sales Data Visualization and Storytelling

## Summary

This project is a Tableau dashboard created as part of a Data Visualization and Storytelling task. I used a sales dataset to create charts for sales trends, country-wise sales, and category-wise profitability, and added key insights to make the data easier to understand.

## Tool Used

- Tableau Public
- CSV Dataset
- GitHub

## What I Created

The dashboard includes:

- Monthly Sales Trend
- Sales by Country
- Profit by Category
- Profit by Country
- Key Insights

I selected different chart types based on the type of information being presented and kept the dashboard simple by avoiding unnecessary colors and clutter.

## Key Insights

- Portugal generated the highest sales among the countries in the dataset.
- Clothing generated the highest profit among the categories.
- Sales showed variation throughout the year, with higher sales in June and December.

## Data Storytelling

The dashboard presents the data in a simple flow:

**Sales Overview → Monthly Trend → Country Performance → Category Profitability → Key Insights**

This helped me understand how charts can be used not only to display data but also to communicate useful information from it.
